# Projet Solo : frontend + backend

Initialisation d'un projet avec un frontend et un backend

# Initialisation du projet:

1. Création du dossier avec les dossiers "frontend" et "backend".
2. Frontend : projet Vite initialisé dans "frontend/"
3. Backend : template de repo cloné dans "backend/"
4. Installation des modules nécessaires avec npm install et vérification de si tout se lance bien dans les 2 fichiers

# Technologies utilisées :

- Vite, React, TypeScript, Github

# Problèmes :

J'ai eu des soucis avec l'installation (je veux dire les npm i sur les différents fichiers) sur le terminal mais j'ai pu régler ça en me remettant dans le bon fichier.

# Inititulé de mon projet :

Je pense faire un projet d'affichage de cartes de personnages de Fire Emblem avec leurs statistiques appelées grâce à une API, en cliquant sur un bouton, on peut classer
les personnages selon leur arme (épée, lance, magie, arc, etc) puis ensuite cliquer sur la carte du personnage qui nous intéresse pour qu'il s'affiche, et on peut observer ses
différentes statistiques (Force, Vitesse, Défense, Charme, également leur classe, etc)

(J'aimerais aussi, si j'ai le temps mettre en place un système pour classer les personnages du meilleur au pire selon leurs statistiques totales)
